赛博女友 · 使用说明
========================================

■ 怎么启动
  双击桌面上的「赛博女友」图标（或开始菜单里的）。
  程序会自己开一个本地服务，并自动打开浏览器。
  想关掉：把那个黑色命令窗口关掉即可。

  程序位置：%LOCALAPPDATA%\Programs\CyberGirlfriend
  数据位置：%LOCALAPPDATA%\赛博女友
  （角色列表、形象图、设置、证书都在这里；删掉这两个文件夹就等于卸载）

■ 第一次使用要填 API Key
  打开页面 → 右上角齿轮「设置」→「Vivix API Key」粘贴你的 Key → 保存设置。
  Key 只存在你自己电脑上，不会上传到任何地方。

  还没有 Key？设置面板里就有三步引导，点「去 vivix.ai 创建 ↗」跳过去：
    ① 打开 platform.vivix.ai，用邮箱注册（Developer Preview 阶段可免费试用）
    ② 登录后点左侧菜单的 API Keys → 新建 → 复制那串 Key
    ③ 回来粘进输入框，点最下面的「保存设置」

  忘了怎么用？点右上角的「?」按钮，里面有完整的图文使用说明。

■ 角色（可以存很多个，随时切换）
  设置 →「角色列表」：
    · 保存当前设置为角色：把现在的形象图 + 人设 + 声线 + 画面比例整体存一份
    · 载入：一键切回某个角色
    · 名字可以直接在卡片上改，改完自动保存
    · 导出角色包 / 导入角色包：换电脑时用，一个文件搬走全部角色

■ 换形象图（重点：比例一定要对）
  Vivix 官方要求：形象图的比例必须和画面比例一致。
  拿横图去跑 9:16 竖版，模型会把人物横向压扁、变窄变形。

  所以设置里的流程是：
    ① 选照片  → ② 选目标比例 / 处理方式 / 取景  → 确认并上传
  处理方式说明：
    · 自动（推荐）：程序自己判断，横图硬裁会切人就改成补边
    · 裁切铺满：按目标比例裁掉多余部分，人物比例不变
    · 补边不裁人：人物完整保留，多余部分用这张图的模糊版补上
  界面左侧是原图、右侧是「将上传」的成品，所见即所得。

  已经是旧图 + 换过画面比例？点「重新裁切当前图片」修一下即可。
  设置里还有一行提示会告诉你当前图配不配得上输出比例。

■ 声线（共 48 个，按来源分 8 组）
  · 女声 / 男声 / 少年正太 / 英文 —— Vivix 官方文档列出的内置音色，已验证可用
  · ElevenLabs —— 需要你自己再填一个 ElevenLabs API Key
  · 候选男声 / 候选少年 / 候选女声 —— 出自阿里 CosyVoice 官方音色表，
      Vivix 文档没列出，可能能用也可能报错，界面上有标注
  · 我的克隆音色 —— 你在 Vivix 工作区克隆过的音色会自动列出来
  · 自定义音色 ID —— 上面都没有就手填

  不确定某个音色行不行？点「试听这个音色」，
  它会真实开一次会话念一句话（会计费），听完点挂断即可。

■ 在手机 / 平板上用
  顶栏有个手机图标，点开有二维码，手机扫一下就能打开（要和电脑同一个 Wi-Fi）。

  · 打字聊天：用 http 地址就行
  · 想在手机开麦说话：必须用 https 地址
    （浏览器不允许 http 页面调用麦克风，这是浏览器的限制）
    首次打开会提示「证书不受信任」，点「高级 → 继续前往」即可，
    这是本机自己签的证书，只对你的局域网有效。

■ 让人物图片能用（重要）
  角色图片必须是一个公网能访问的地址，Vivix 的服务器要去抓它。
  点「确认并上传」后，程序会把它传到你的 GitHub 仓库并拿到公网链接。

  需要你有 GitHub 上传通道，二选一：
    ① 本机装过 gh 命令行并执行过 gh auth login
    ② 设置环境变量 GITHUB_TOKEN 为你的 GitHub 个人访问令牌（勾选 repo 权限）
  没有通道时上传会失败并提示，此时也可以直接把一个公网图片 URL
  填进「角色图片 URL」那一栏。

■ 常见问题
  · 页面打不开 / 白屏：可能是端口被占了，右键桌面图标…不行就重启电脑；
    或者编辑 %LOCALAPPDATA%\赛博女友\config.json 把 port 改成别的数字。
  · 她说不了话 / 没反应：多半是 API Key 没填、余额不足，或角色图片不是公网地址。
  · 她说半句突然停了：先看是不是你自己紧接着又发了消息——以前那会把她
    正在说的那句掐断（答案越长越明显），现在改成排队了：她说完这句，再依次
    回答你排着的消息；真想立刻让她闭嘴，点「她正在说…」右边的「打断」按钮。
    如果谁都没动她也停在半句，聊天里会出现一行灰字，写的是服务端给的原因，
    把那行字发我就能顺着查。
  · 人物变形：形象图比例和画面比例没对上，按上面「换形象图」重做一次。
  · Windows 提示「已保护你的电脑」：这是未签名的自编译程序，
    点「更多信息 → 仍要运行」即可。

■ 注意
  这是单机自用程序：服务开在你自己的电脑上，浏览器访问的是本机地址，
  只有你和同一个局域网里的人能用。

  想让外网所有人都能用？同一份程序支持「公网部署」——
  把它挂到一个免费托管平台上就能得到一个公网网址，发给谁谁就能打开。
  部署文件（Dockerfile / render.yaml）和逐步教程都在仓库的 DEPLOY.md 里。
  公网版的设计是「每位使用者自带自己的 API Key」，所以别人的用量不会算到你头上。
